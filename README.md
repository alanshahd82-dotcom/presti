# PrestigeCars — تطبيق الجوال

تطبيق React Native يعرض موقع [PrestigeCars.ma](https://www.prestigecars.ma/) بشكل تطبيق موبايل احترافي.

## المتطلبات

- Node.js >= 18
- JDK 17 (للأندرويد)
- Android Studio أو Xcode (للـ iOS)

## التثبيت والتشغيل

```bash
# تثبيت المكتبات
npm install

# تشغيل على أندرويد
npx react-native run-android

# تشغيل على iOS
cd ios && pod install && cd ..
npx react-native run-ios
```
